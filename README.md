## 🌿 Git Branching Guide (Quick Reference)

We maintain a clean Git Flow branching architecture for team collaboration:

| Branch | Purpose | Target |
| :--- | :--- | :--- |
| `main` | Production-ready stable release | Protected |
| `develop` | Active integration branch | `main` |
| `feature/*` | New models, algorithms, and pipelines | `develop` |
| `docs/*` | System documentation & specs | `develop` / `main` |

### 🛠️ Common Git Commands

```bash
# Switch to integration branch
git checkout develop

# Create a new feature branch
git checkout -b feature/risk-model develop

# Create a documentation branch
git checkout -b docs/api-specs develop

# Push branch to remote repository
git push -u origin <branch-name>
```
